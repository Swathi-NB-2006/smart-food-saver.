# Smart Food Saver

## Problem
College canteens often waste surplus food because students and volunteers are unaware of its availability.

## Solution
Smart Food Saver is a web application that helps canteens list surplus food and allows students and volunteers to request its collection.

## Features
- Dashboard showing food statistics
- Add surplus food details
- View available food
- Request food collection
- Track food saved from wastage

## Technologies Used
- Python
- Streamlit

## How to Run

Install dependencies:

`python -m pip install -r requirements.txt`

Run the application:

`python -m streamlit run app.py`
